# 🎮 Танки — Битва с Боссами

Аркадная игра в жанре «танчики», написанная на Python с использованием библиотеки **Pygame**. 
Проект прошел рефакторинг из одного файла в модульную структуру.

![Pygame](https://img.shields.io/badge/Pygame-2.5%2B-green?logo=pygame&logoColor=white)

---

## 🚀 О проекте

Это не просто «танчики». Здесь есть система боссов, разные виды оружия, система бонусов и даже погодные эффекты.
Основная цель рефакторинга — сделать код читаемым и масштабируемым.

### ✨ Особенности
- **3 уникальных босса:** Танк-Берсерк, Дрон-Убийца и Танк-Мегатрон.
- **7 видов оружия:** от обычных пуль до самонаводящихся ракет и камикадзе.
- **Динамические карты:** от арены до пустоши с лавой.
- **Система бонусов:** аптечки, ускорение, двойной выстрел.
- **Эффекты:** тряска экрана, партиклы, следы от взрывов.

## 🛠️ Структура проекта

```text

├── main.py              # Точка входа в игру (запуск цикла)
├── README.md            # Документация
├── .gitignore           # Исключения для Git
│
├── src/                 # Исходный код игры

│   │
│   └── utils/           # Вспомогательные утилиты
│       ├── __init__.py

│
└── sounds/              # Аудиофайлы (.wav, .mp3)
